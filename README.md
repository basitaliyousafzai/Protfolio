# Basit Ali — Professional Portfolio

A polished, responsive single-page portfolio for **Basit Ali**, Full-Stack Software Engineer based in Rawalpindi, Pakistan.

## Included

- Animated hero section with professional role rotation
- Responsive Bootstrap navigation
- Particle backgrounds and GSAP scroll animations
- Professional profile summary and technical toolkit
- Multi-Tech Solutions experience timeline
- Verified client and enterprise project portfolio with live website links
- Featured GitHub repositories
- Education and contact sections
- GitHub, LinkedIn, portfolio, email, and location links
- Responsive cards, gradients, hover states, and back-to-top navigation

## Run locally

Open [`Portfolio.html`](./Portfolio.html) in a browser, or serve the repository with any static web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/Portfolio.html`.
